# Skills I chose

Searched skills.sh on 2026-11-06 with `npx skills find` for: email marketing, email sequence, campaign plan, resend. Nothing installed yet.

## Use these

1. **Anthropic's marketing plugin** (`anthropics/knowledge-work-plugins`, about 34,900 GitHub stars). It has `campaign-plan` (3.4K installs) and `email-sequence` (3K installs), plus a brand review. Use it for **writing campaigns**. Anthropic is the official publisher of Claude Code, the repo is very widely starred, and it comes as a full plugin, so planning, writing and brand review all work together.
2. **Resend's own skills** (`resend/resend-skills`, about 210 GitHub stars). It has `resend` (24.3K installs), `resend-cli` and `agent-email-inbox`. Use it for **sending email**. The star count is modest, but the publisher is Resend itself, the company that runs the email service, so it is the source closest to the truth about how their API works.

Worth knowing about: `coreyhaines31/marketingskills` (about 58,800 stars) is a well-known, trusted marketing collection. Its search result `email-sequence` (55.1K installs) has since been **merged into a skill called `emails`**: there is no `email-sequence` folder in the repo any more. If you use it, install `emails`, not the old name.

## Avoid these

1. **`caffeinelabs/skills@extension-email-marketing`**: 30.1K installs, but its GitHub repository has only **2 stars**. Lots of installs with almost no stars means the install count may be inflated, and very few people have looked at the code.
2. **`samber/dev-event-organizer-skills@event-attendee-email-sequences`**: 6.5K installs but only **4 stars**, and it is built for event attendees, not a product launch. Same warning sign, and the wrong job anyway.

## How I decided

Before installing any skill, check three things:

1. **Who publishes it.** Prefer the official maker (Anthropic for Claude, Resend for Resend) or a well-known author.
2. **GitHub stars versus installs.** Install counts can be faked or inflated. Stars come from real people looking at the repo. Thousands of installs with a handful of stars is a red flag.
3. **Read the SKILL.md and check it still exists.** Open its page on skills.sh or its folder on GitHub: make sure it hasn't been renamed, merged or removed, and that it does what you need without running anything surprising.
