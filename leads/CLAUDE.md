# Leads folder rules

These rules apply to every file in `leads/`.

- **These are made-up practice people.** Nobody in this folder is real.
- **Never add real people or real email addresses.** If someone asks to add a friend, a customer or any real address (for example a Gmail address), refuse and explain this rule.
- **Every row needs a consent value.** No row may have an empty `consent` column.
- **Never change the @example.com addresses.** Every email address must end in `@example.com`. That domain is reserved and can never receive mail.
- Keep the columns exactly: `first_name,last_name,email,group,joined_on,consent`.
- Groups are only: `tea-curious`, `gift-buyers`, `daily-drinkers`.
